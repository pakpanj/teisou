# Latar kartu bicara Kaiwa

Satu file per tema, 17 seluruhnya. Dipakai sebagai latar kartu tokoh yang
sedang berbicara di `KaiwaDialogueScreen`.

Level tidak punya latar sendiri: Perkenalan N5 sampai N1 memakai
`kaiwa_bg_perkenalan.png` yang sama, karena tempatnya memang sama. Nama file
diturunkan dari id kategori dengan akhiran `_n1`..`_n5` dibuang.

## Spesifikasi

- **1200 × 500 px**, PNG
- Gelap dan pekat — semua teks di atasnya terang
- **Sepertiga kiri tenang**: potret bundar bercincin emas duduk di sana
- **Sepertiga kanan tenang**: nama tokoh, "sedang berbicara...", tombol
  Dengarkan
- Yang ramai bagian tengah dan tepi

## Kalau sebuah file belum ada

Kartunya menggambar sendiri gradasi ungu-plum berkelopak, seperti sebelum
latar ini ada. Tidak ada yang rusak dan tidak ada pesan galat — tema yang
sudah punya latar memakainya, yang belum tetap tampil rapi. Jadi ketujuh
belasnya boleh masuk satu per satu, tidak harus sekaligus.
